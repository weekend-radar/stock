How to refresh

  1. One tap (quickest): press ⟳ Refresh prices. The page asks Yahoo Finance for each stock, the STI ETF and the STI index. Prices you typed in are replaced by live ones. If it fails, the browser or proxy is blocking it. Use option 2.
  2. Automatic every hour (recommended): use GitHub Pages, free.
    1. Create a GitHub repository. Upload this page as index.html, plus fetch_prices.py.
    2. Create the file .github/workflows/update-prices.yml and paste in the workflow file provided.
    3. Repository Settings → Pages: deploy from the main branch.
    4. Repository Actions → Update SG prices → Run workflow once. It creates data.json.
    5. Open your Pages link. The page reads data.json when it loads, and uses it for charts if the live call is blocked.
    The schedule runs hourly on weekdays during SGX hours (Singapore time). GitHub can delay scheduled runs.
  3. Manual: tap a price to type a new one. For a chart, import a CSV (see the Chart tab).

Opening the file straight from your phone or PC works for options 1 and 3. Option 2 needs the page to be hosted, because browsers block reading data.json from a local file.

What updates by itself, and what does not

  • Automatic: prices, daily change, STI and STI ETF cards, price charts.
  • Manual: analyst ratings and targets, yields, fund and bond rates. Edit the STOCKS and FUNDS lists near the top of the page script, using the sources below.

Data sources

Yahoo Finance Used for prices and charts. Delayed quotes, not real-time. SGX stocks use the code plus .SI (for example D05.SI). Unofficial data feed with no guarantee. Cannot be read directly by most browsers, hence the proxy.
SGX The exchange itself. Check the official quote before you trade.
SGinvestors.io – STI target prices Source of the analyst ratings and average targets in this page. Update manually.
Dividends.sg Dividend history and yield. Update yields manually.
SGYieldHub · MAS T-bill and Savings Bond rates. MAS is the official source. Update the Funds tab manually.
Google Finance Link inside each stock review for a quick second price check.
